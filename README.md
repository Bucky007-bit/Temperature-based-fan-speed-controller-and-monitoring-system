# Temperature-Based Fan Speed Controller and Monitoring System

This project is a temperature-controlled fan speed system that uses an ESP32 microcontroller to monitor temperature and adjust the fan's speed accordingly. It also provides real-time data monitoring and control capabilities via the Blynk IoT platform.

## Overview

The **Temperature-Based Fan Speed Controller and Monitoring System** is designed to provide efficient cooling by adjusting the fan's speed based on ambient temperature. It uses an ESP32 microcontroller to read temperature data from a DS18B20 sensor, control the fan speed through a TIP120 transistor, and provide real-time monitoring and control using the Blynk IoT platform.

---

## Features

- Automatic fan speed adjustment based on temperature.
- Real-time temperature and fan speed monitoring via the Blynk IoT platform.
- Remote control of fan speed and custom threshold settings via a smartphone.
- Protection against back EMF using a diode.
- Compact and modular design for easy assembly.

## Components Required

1. **ESP32 DevKit V1** - Central microcontroller for processing and communication.  
2. **DS18B20 Temperature Sensor** - Measures ambient temperature with high accuracy.  
3. **TIP120 Transistor** - Amplifies control signals to drive the fan.  
4. **12V DC Fan** - Adjusts speed based on temperature.  
5. **1N4007 Diode** - Protects the circuit from back EMF.  
6. **Resistor (10kΩ)** - Pull-up resistor for the DS18B20 sensor.  
7. **7805 Voltage Regulator** - Steps down 12V DC to 5V DC for the ESP32.  
8. **External Power Supply (12V Adapter)** - Powers the fan.  
9. **Connecting Wires** - For circuit connections.  
10. **Breadboard/PCB** - For mounting components.

## Working Principle

### 1. **ESP32 DevKit V1**  
   - Reads temperature data from the DS18B20 sensor using the OneWire protocol.  
   - Generates a PWM signal to control the fan speed via the TIP120 transistor.  
   - Sends real-time data to the Blynk IoT app for monitoring and control.

### 2. **DS18B20 Temperature Sensor**  
   - Provides accurate temperature data with a resolution of 9 to 12 bits.  
   - Communicates temperature readings to the ESP32 for processing.

### 3. **TIP120 Transistor**  
   - Acts as a switch and amplifier to control the fan's power.  
   - Receives PWM signals from the ESP32 to adjust the fan speed proportionally.

### 4. **12V DC Fan**  
   - Operates at variable speeds based on the PWM signal.  
   - Powered by an external 12V adapter for optimal performance.

### 5. **Diode (1N4007)**  
   - Protects the circuit from reverse voltage spikes generated by the fan.

### 6. **Blynk IoT Platform**  
   - Enables remote monitoring and control of the system via a smartphone.  
   - Provides real-time graphs, gauges, and alerts for temperature and fan speed.

### 7. **External Power Supply**  
   - Powers the fan and provides a stable 12V DC.  
   - The 7805 voltage regulator steps down the voltage to 5V for the ESP32.

## Installation and Setup

1. **Hardware Setup**:
   - Connect the DS18B20 sensor to the ESP32 as per the circuit diagram.
   - Use the TIP120 transistor to interface the fan with the ESP32.
   - Connect the 1N4007 diode across the fan terminals for flyback protection.
   - Provide power to the ESP32 and fan using the 7805 voltage regulator and a 12V adapter.

2. **Software Setup**:
   - Install the [Arduino IDE](https://www.arduino.cc/en/software) and configure it for ESP32.
   - Add the required libraries for DS18B20 and Blynk.
   - Upload the code to the ESP32.

3. **Blynk Configuration**:
   - Download the Blynk app from [Google Play Store](https://play.google.com/store/apps) or [Apple App Store](https://www.apple.com/app-store/).
   - Create a new project and configure widgets for temperature and fan speed monitoring.
   - Copy the authentication token and include it in the code.
